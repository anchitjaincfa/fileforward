# FileForward

A privacy-first educational prototype for US freelancers who may have missed tax filings.

**Not tax or legal advice.** FileForward is not a CPA firm, law firm, tax preparer, referral service, or government agency.

## Included

- Deterministic in-browser assessment with conservative urgent-notice routing
- Official and free-help links
- Printable private handoff plan
- Visibly synthetic marketplace demo
- Public methodology and product boundaries

## Privacy promise

Answers exist only in JavaScript memory. There are no accounts, cookies, browser storage, analytics, API calls, server routes, free-text fields, uploads, or answer-dependent network requests.

The product plan went through four adversarial Claude review rounds before implementation. Those reviews changed it from a lead-generation marketplace into a privacy-first educational product with explicit gates before any real firm or user data can be introduced.
